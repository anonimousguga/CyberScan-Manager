CyberScan Manager

Integrante: Gustavo Batista de Souza
Contexto do Projeto

O CyberScan Manager é um projeto acadêmico desenvolvido para a disciplina de Programação Orientada a Objetos do Bacharelado em Cibersegurança da PUCPR.

A proposta do sistema consiste no desenvolvimento de uma ferramenta de análise de vulnerabilidades em dispositivos de rede, permitindo o cadastro de equipamentos, verificação de portas abertas e geração de relatórios de segurança.

O projeto busca aplicar, na prática, conceitos fundamentais de Programação Orientada a Objetos, como encapsulamento, herança, polimorfismo, abstração, interfaces e tratamento de exceções, utilizando a linguagem Java.

Além disso, o sistema pretende implementar funcionalidades complementares, como:
1.Interface gráfica;
2.Persistência de dados;
3.Leitura de arquivos CSV;
4.Serialização de objetos;
5.Organização modular do código;
6.Verificações reais de portas utilizando sockets TCP.

O objetivo principal é unir conceitos de desenvolvimento de software com fundamentos introdutórios de cibersegurança, criando uma aplicação capaz de realizar análises básicas de rede em um contexto corporativo.
