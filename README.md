Projeto: CyberScan Manager

Integrante:
Gustavo Batista de Souza

Contexto do meu Projeto:

O CyberScan Manager é um projeto acadêmico desenvolvido para a disciplina de Programação Orientada a Objetos do Bacharelado em Cibersegurança da PUCPR.
A proposta do sistema consiste na simulação de um ambiente corporativo de gerenciamento e análise de vulnerabilidades em dispositivos de rede, permitindo o cadastro de equipamentos, execução de escaneamentos simulados e geração de relatórios de segurança.

O projeto busca aplicar, na prática, conceitos fundamentais como encapsulamento, herança, polimorfismo, abstração, interfaces e tratamento de exceções, utilizando a linguagem Java.

além disso, o sistema pretende implementar funcionalidades complementares, como:
1° Interface gráfica;
2° Persistência de dados;
3° Leitura de arquivos CSV;
4° Serialização de objetos;
5° Organização modular do código.

O objetivo principal é unir conceitos de desenvolvimento de software com fundamentos da matéria e também cibersegurança, simulando o funcionamento de uma ferramenta de análise de vulnerabilidades em um contexto corporativo.
